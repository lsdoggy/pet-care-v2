## Context

SecurityConfig, WebConfig, FileStorageService, vet API, PetPhotoController и регистрация.

## Goals / Non-Goals

Закрыть прямую публичную выдачу ветеринарных файлов и ограничить регистрацию приглашениями. Изменения ограничены контрактами, необходимыми для этого блока альфы.

## Decisions

Ввести проверку владельца для чтения вложений по связанной записи и покрыть ранее сохранённые URL. Адаптировать просмотр и скачивание в web и Android через существующие API-клиенты. Проверить защиту фото в релизной ревизии. Добавить одноразовые приглашения с атомарным погашением и отключаемой выдачей; сохранить вход действующих пользователей.

## Risks / Trade-offs

MockMvc/H2 для владельца, анонима, чужого аккаунта, старых ссылок и повторного приглашения. Сквозное открытие PDF и фото в web и Android. Для внешних проверок зафиксировать версию, окружение и недостающие доступы. Использовать вымышленные данные до допуска.
