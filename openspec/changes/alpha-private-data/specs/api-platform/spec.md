## MODIFIED Requirements

### Requirement: Публичные медицинские вложения

Система SHALL проверять право доступа к записи перед выдачей любого связанного файла, включая ранее сохранённые ссылки.

#### Scenario: Пользователь открывает файл по сохранённой ссылке

- **WHEN** запросы к старому и новому url вложения проверяется в целевом окружении
- **THEN** владелец получает файл, а аноним и другой аккаунт получают 401 и 404 соответственно.

## ADDED Requirements

### Requirement: Одноразовые приглашения альфы

В режиме закрытой альфы регистрация SHALL требовать действующее приглашение. Погашение приглашения и создание аккаунта должны быть атомарными.

#### Scenario: Одновременное использование приглашения

- **WHEN** два запроса одновременно используют один код
- **THEN** создаётся максимум один аккаунт, а вход существующих пользователей остаётся доступен.
