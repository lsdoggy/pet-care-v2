## ADDED Requirements

### Requirement: Подготовить восстановление аккаунта по email

Система SHALL разделять токены сброса пароля и возврата после деактивации. Токены должны иметь срок действия и погашаться атомарно. Ответ на запрос сброса не раскрывает наличие аккаунта.

#### Scenario: Две попытки использовать действительную ссылку

- **WHEN** переход по ссылке из письма проверяется в целевом окружении
- **THEN** только первая завершает восстановление; просроченная ссылка не меняет аккаунт.
