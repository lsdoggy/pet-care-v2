## ADDED Requirements

### Requirement: Реализовать Web Push для iPhone

Установленное веб-приложение SHALL подключать Web Push по явному действию пользователя. Сервер должен привязывать подписку к аккаунту, прекращать отправку после отвязки и исключать чувствительные данные из содержимого уведомления.

#### Scenario: Напоминание на iPhone

- **WHEN** напоминание в установленном веб-приложении проверяется в целевом окружении
- **THEN** уведомление появляется при закрытом интерфейсе, а нажатие открывает целевой экран того же origin.
