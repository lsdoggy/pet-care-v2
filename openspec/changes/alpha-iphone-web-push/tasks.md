Границы изменений: Android сохраняет существующий транспорт. Web Push подключён
к общей доставке через NotificationService. Подписки Apple изолированы от
реестра нативных устройств. Service worker получает сигнал без payload и
открывает главную страницу того же origin.

Физический iPhone и тестовый публичный HTTPS с VAPID остаются необходимы для
приёмки по [инструкции](../../../docs/alpha-web-push.md).
