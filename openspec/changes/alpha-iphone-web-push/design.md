## Context

apps/web, настройки уведомлений, backend notification/device.

## Goals / Non-Goals

Доставлять те же напоминания в установленном веб-приложении на iOS 16.4+. Изменения ограничены контрактами, необходимыми для этого блока альфы.

## Decisions

Добавить manifest, service worker и явное включение push из установленного приложения. Хранить подписки с привязкой к аккаунту, подключить Web Push к существующему планировщику, удалять недействительные подписки и отвязывать при выходе. Ограничить маршруты из payload собственным origin. Использовать нейтральный текст на экране блокировки.

## Risks / Trade-offs

Тесты владения подпиской и выбора транспортов, ручная проверка установки, разрешения, доставки, перехода и выхода на физическом iPhone. Для внешних проверок зафиксировать версию, окружение и недостающие доступы. Использовать вымышленные данные до допуска.
