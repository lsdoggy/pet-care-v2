## ADDED Requirements

### Requirement: Подготовить подписанное Android-приложение с push

Подписанная Android-сборка SHALL получать штатные push-напоминания через Expo/FCM v1 при разрешении пользователя.

#### Scenario: Напоминание о задаче в фоне

- **WHEN** штатное напоминание при закрытом интерфейсе android проверяется в целевом окружении
- **THEN** устройство получает уведомление и открывает нужную задачу по нажатию; после выхода отправка для прежнего аккаунта прекращается.
