## Context

apps/mobile/eas.json, usePushRegistration, ExpoPushSender, настройки уведомлений.

## Goals / Non-Goals

Доставлять штатные напоминания в самостоятельной Android-сборке. Изменения ограничены контрактами, необходимыми для этого блока альфы.

## Decisions

Настроить EAS и FCM v1 для текущей Expo-интеграции, HTTPS API и серверный транспорт. Проверить разрешение, канал, регистрацию и отвязку устройства, обработку недействительных токенов и переход по уведомлению. Зафиксировать способ распространения и обновления подписанной сборки.

## Risks / Trade-offs

Автоматические проверки регистрации и маршрутизации, физический Android для установки, обновления, доставки в фоне, отказа в разрешении и смены аккаунта. Для внешних проверок зафиксировать версию, окружение и недостающие доступы. Использовать вымышленные данные до допуска.
