## Context

infra/compose.vps.yml, infra/Caddyfile, README, docs/mobile-safari-pilot.md и #34/#53.

## Goals / Non-Goals

Развернуть и принять окружение для закрытой альфы до 100 участников. Изменения ограничены контрактами, необходимыми для этого блока альфы.

## Decisions

Зафиксировать ревизию API, web и Android; настроить HTTPS, PostgreSQL, миграции, мониторинг API, SMTP, push и диска. Настроить резервное копирование БД и загрузок и выполнить пробное восстановление. Подготовить канал поддержки, обработку удаления данных и порядок остановки приглашений. Начать с внутренней проверки, затем предложены 10–15 участников и расширение до 100 по результатам.

## Risks / Trade-offs

Compose validation, smoke через внешний HTTPS, физические Android/iPhone, отчёт восстановления с версиями и результатами. Реальные данные только после допуска. Для внешних проверок зафиксировать версию, окружение и недостающие доступы. Использовать вымышленные данные до допуска.
